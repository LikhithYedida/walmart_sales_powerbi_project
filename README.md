# Walmart Sales Analysis – Power BI Project

### 📌 Overview
This Power BI dashboard analyzes Walmart sales trends across stores, focusing on 
key metrics such as weekly sales, fuel price, temperature, unemployment rate, and 
seasonality. The goal is to uncover factors influencing retail performance and 
generate actionable business insights.

---

## 🚀 Key Features
### ✔ KPI Cards
- Total Weekly Sales
- Average Temperature
- Average Fuel Price
- Average Unemployment Rate

### ✔ Visuals
1. **Weekly Sales by Year (Line Chart)**
2. **Weekly Sales by Store (Bar Chart)**
3. **Sales vs Fuel Price Trend**
4. **Sales vs Temperature**
5. **Data Model with 4 Related Tables**

---

## 🔍 Insights
- **2011 had the highest overall weekly sales**
- **Stores with larger size categories outperform smaller ones**
- **Fuel price shows a mild negative correlation with demand**
- **Temperature influences seasonal purchasing behavior**
